SPOT IT! PREMIUM - ORGANIZED UPDATE

1. Upload index.html and background.png to the Spot It Premium repository.
2. Copy original Food Express music.mp3, bling.mp3 and reveal.mp3 into audios/. The original audio files were not supplied with this version.
3. Settings > Load Food Preset or Create New Set. Choose Word/letter, Picture, or Picture+word. Add clues, edit clues, or remove them.
4. Close Settings > Edit Object Positions; drag each clue. In two-team mode, each board is independent.
5. At completion, the board shows the time, score, and all found items. Other team continues.
6. Export JSON to preserve custom sets and positions. Pictures embedded via upload/paste are portable; external URL pictures may not be.
7. Browser/multi-touch testing is recommended before deployment. Cross-device live synchronization is not included.
